# 标题

## 超级马里奥

开发一个网页版的超级马里奥游戏(World1,1~4),要尽量还原原版的UI、操作、各种关卡细
节,各方面尽量做的一模一样。



## Rust+GPUI实现macOS版类微信APP
开发一个类似微信的IMApp。同时实现macOS客户端和后端。客户端使用Rust+GPUI(可以使用
gpui-base或/和gpui-component),后端使用Go(Echo+S),功能要求真实可用,不允许
mock数据。需支持在同一台Mac上运行两个客户端实例,用两个账号互相聊天验证。

功能要求:

1.注册登录:用户名密码注册登录即可
2.聊天:支持私聊和群聊,支持创建群聊、邀请好友入群、退出群聊。私聊和群聊都需要支持文
本、图片、视频消息;消息实时送达,离线消息上线后可收到;聊天记录持久化,重启后仍
在。
3.通讯录:搜索用户、发送好友申请、接受/拒绝申请、删除好友;
4.朋友圈:发布动态(文字、图片最多9张、视频);浏览自己和好友的动态时间线;点赞、取
消点赞;评论、回复评论;删除自己的动态。

在保证以上基础功能的前提下,UI和交互不要模仿微信,请按你认为最好的设计来做,拿出你最好
的水平,别到时候让我反问:Isthatthebestyoucando??
